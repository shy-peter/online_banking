🔧 Storage Bucket Test

This tool helps you test if your Appwrite storage bucket is set up correctly.

Step 1: Check Your Setup

Before testing, make sure you have:

  • ✅ Created a bucket with ID: files
  • ✅ Set permissions: read("any") and write("any")
  • ✅ Allowed file extensions: jpg,jpeg,png,gif,webp,pdf,doc,docx,txt
  • ✅ Set max file size: 10485760 (10MB)

Step 3: Manual Setup Instructions

If the test fails, follow these steps:

  1. Go to Appwrite Console
  2. Select your project
  3. Navigate to Storage
  4. Click "Create Bucket"
  5. Use these exact settings:
    • Bucket ID: files
    • Name: Files
    • File Security: ✅ Enabled
    • Max File Size: 10485760
    • Allowed Extensions: jpg,jpeg,png,gif,webp,pdf,doc,docx,txt
  6. After creating, go to bucket settings and add permissions:
    • read("any")
    • write("any")

Step 4: Enable Storage in App

Once the bucket is working, update your app:

  1. Open src/pages/EnhancedSignup.tsx
  2. Find the line: const [useStorageFallback, setUseStorageFallback] = useState(true);
  3. Change it to: const [useStorageFallback, setUseStorageFallback] = useState(false);
  4. Save the file and test the signup form
